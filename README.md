# NONZERO

A private, tracker for non-zero days.

Inspired by u/ryans01’s “No More Zero Days” comment on Reddit. Data never leaves the browser unless you download a backup

This is not medical advice.

## What it does

- Three 1–10 scales: personal space, hygiene, wellbeing (with anchors)
- A kind daily read and one suggested next move (scales + lists only)
- Resettable care list with point values
- Short / medium / long goals you can “touch”
- Quiet logs: weight, measurements, calories, exercise — no commentary
- Week / month / year look-back
- Light and dark mode
- JSON backup and restore

## Use it now

Open `index.html` in a phone browser. Add to Home Screen if you want it to feel like an app.

Use the **same browser** on that phone or you will not see the same data.

Each person who opens the link gets their own private data on their own device.

## Backup

Settings on the page → Download backup. Restore the JSON file if you switch phones or clear site data.
